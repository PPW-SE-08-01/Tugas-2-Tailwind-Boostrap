RG ECOPRINT - COMPANY PROFILE (Bootstrap 5.3)

Struktur:
- index.html     -> Beranda
- tentang.html   -> Tentang Kami
- produk.html    -> Produk
- kontak.html    -> Kontak & Kolaborasi
- style.css      -> Tema saja: warna & font (CSS variables) + beberapa helper kecil
- assets/        -> Gambar/logo

Catatan:
- Bootstrap 5.3.3 (CSS + JS bundle) dimuat lewat CDN jsDelivr; style.css dimuat setelahnya.
- Layout memakai grid/utility/komponen Bootstrap langsung di HTML
  (row/col, navbar, card, list-group, form-control, btn, dst).
- Menu hamburger mobile memakai komponen collapse Bootstrap (tanpa script.js).
